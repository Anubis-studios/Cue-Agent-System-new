# 🎯 Cue Agent System v2

Improved multi-agent AI platform with security fixes and complete functionality.

## ✨ Key Improvements
- ✅ Safe math evaluation (AST-based, no eval!)
- ✅ Complete SQLite database layer
- ✅ Response caching and retry logic
- ✅ Real video worker implementation
- ✅ Enhanced frontend with chat history
- ✅ Improved CLI with commands
- ✅ Tightened CORS and security

## 🚀 Quick Start
```bash
cd backend && pip install -r requirements.txt
cd ../frontend && npm install
export OPENROUTER_API_KEY=your_key_here
./scripts/dev.sh
```
